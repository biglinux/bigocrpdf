# Benchmark datasets

Two corpora, and a rule about what may be committed.

## Synthetic fixtures

Generated by `benchmarks/make_synthetic_ocr_fixtures.py` from text written in
this repository, drawn with whatever fonts the host has. Ours, no third-party
terms, exact ground truth by construction — the drawing code returns the text
it drew rather than repeating it, so the two cannot drift apart.

Degraded variants share their clean sample's ground truth: a degradation moves
pixels and leaves the text alone.

```sh
python3 benchmarks/make_synthetic_ocr_fixtures.py --out data/benchmarks --tier gate
```

## DharmaOCR-Benchmark

`Dharma-AI/DharmaOCR-Benchmark`, pinned to revision
`e8f4bb516839c1a0a32ee0234b3cbcd5aa5c10d3`. 496 full pages of Brazilian
Portuguese — printed text, legal and administrative documents, and handwriting
— which is the language and the document class this program is actually for.

Licensed under the **Community Data License Agreement – Permissive 2.0**. It
permits commercial use, permits redistribution provided the agreement text
travels with the data, and states that derived results carry no restriction at
all:

> This agreement does not impose any restriction or obligations with respect to
> the use, modification, or sharing of Results.

That last sentence is why the baseline below may be committed.

Requires the `datasets` package (`python-datasets` on Arch/Manjaro, `pip install
datasets` elsewhere).

```sh
python3 benchmarks/prepare_benchmark_datasets.py --datasets dharmaocr --out data/benchmarks
```

Two properties of the corpus are worth knowing before reading a number from it.
Some pages are rendered in capitals while the ground truth keeps the original
casing, so a case-sensitive CER overstates the error by roughly a factor of
three; and one subset is handwritten, which a printed-text recogniser will not
read.

## What is committed

`data/` is ignored. No image, no transcription and no page of any corpus enters
the repository — the datasets are downloaded or generated on the machine that
runs the benchmark.

What is committed is `benchmarks/baselines/<host-class>/*.jsonl`: counts,
timings, error rates, model digests and sample ids. It carries no text from any
corpus, which is what keeps a GPL-3 repository clear of any third-party data
terms. Verify before committing a new one:

```sh
python3 -c "import json,sys; [print(k) for k,v in json.loads(open(sys.argv[1]).readline()).items() if isinstance(v,str) and len(v)>60]" \
  build/bench/candidate.jsonl
```

Only digests and relative paths should appear.
